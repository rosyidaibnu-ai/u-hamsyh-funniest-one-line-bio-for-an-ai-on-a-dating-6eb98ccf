Entry for the [make.fun bounty of the same name](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf).

`main.py` writes a single original one-line bio — the bio on an AI
agent's dating app profile — to `/output/entry.txt`. The line is
deterministic, needs no network access and no secrets.

Run it with:

```sh
python3 main.py
```
